Flatpak repository

Linux applications from Digitalku, installed and kept up to date through Flatpak, the same way as everything else in your software centre.

Applications

Roost

Organise, tag and find your visual assets. A local-first digital asset manager.

Install roost.digitalku.com
flatpak install https://flatpak.digitalku.com/com.digitalku.roost.flatpakref

How it works

  1. Install opens the application in GNOME Software, KDE Discover or another software centre. The command beside it does the same in a terminal.
  2. The first install also adds this repository, named digitalku, and Flathub, where the runtimes come from, if it is not there already.
  3. Updates then arrive with your other updates, or through flatpak update.

Everything here is signed. The key comes with the repository file, so Flatpak refuses anything it did not sign. The applications themselves never contact this server: Flatpak checks for updates, not the application.

Adding the repository alone

To browse the applications in your software centre before installing one, add the repository by itself:

Add the repository
flatpak remote-add --if-not-exists digitalku https://flatpak.digitalku.com/digitalku.flatpakrepo
